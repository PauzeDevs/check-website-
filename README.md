# PauzeDevs — check-website-

A responsive, static PauzeDevs landing page with a dark graphite interface, restrained cyan/indigo accents, CSS-built glass panels, and subtle reveal motion inspired by the visual language of ThreeUI.

## Design direction
- Technical and minimal: strong typography, fine grid lines, quiet metadata, no decorative stock imagery.
- CSS-only abstract interface art; no runtime framework or third-party JavaScript dependency.
- Responsive navigation, project cards, scroll reveals, and reduced-motion support.
- Separate branding from PauzeX and the personal “Pauze is a dev” site.

## Files
- `index.html` — page structure and copy
- `styles.css` — responsive design system and CSS illustrations
- `script.js` — mobile navigation, current year, and accessible reveal behavior

## Run locally
Open `index.html` in a browser. Google Fonts are optional; the page falls back to system sans-serif fonts if they cannot load.

## Deploy with GitHub Pages
1. Open this repository's **Settings → Pages**.
2. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.
3. Wait for the Pages deployment check to finish.

## Project links
